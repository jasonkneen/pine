# Working on pine's page

Before you change anything under `src/`, and when you review such a change, read the shadcn skill
(`.agents/skills/shadcn/SKILL.md` and every file in its `rules/`), then `DESIGN.md`, and hold the
change to both. The skill says how shadcn works; `DESIGN.md` says how pine holds to it.

@.agents/skills/shadcn/SKILL.md
@DESIGN.md

The rest of what there is to know about this package (commands, tests, layout, the rules that keep
it safe) is in the repository's `AGENTS.md` and in `docs/references/desktop.md`.
